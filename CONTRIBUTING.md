# Contributing
- Open an issue first for anything larger than a typo. Use the labels `type:*`, `area:*`, `priority:*`.
- Work on a branch and open a pull request. Squash merge. At least one review by someone other than the last pusher.
- Run `npm test` before pushing. For UI changes also run `npm install` and `npm run a11y`.
- Never commit phone numbers, tokens or personal data. Contacts stay in the visitor's browser.
- Wordings must be neutral, in every supported language, with no commas, periods or line breaks.
- Keep the UI right-to-left for Hebrew and Arabic. New UI strings go into `i18n/strings.json` for all languages.
